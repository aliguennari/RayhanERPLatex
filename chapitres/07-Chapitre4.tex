\section{Introduction}
Après avoir établi le plan directeur de l’application Rayhan ERP au chapitre précédent, nous abordons la mise en œuvre technique du projet. Ce chapitre constitue le pont entre la théorie et la pratique, concrétisant les spécifications en composants logiciels fonctionnels. Nous présentons ici l’écosystème technologique (matériel, Framework et base de données), en explicitant la pertinence de chaque choix pour garantir la performance du système. Pour conclure, une présentation des interfaces graphiques permettra d’illustrer la matérialisation des besoins métiers et l'ergonomie de la solution finale. \par
\section{Environnement de développement}
Cette partie expose l'environnement de développement de Rayhan ERP. Nous y justifions les choix technologiques et les outils qui ont été indispensables à la conception, au codage et au pilotage de la solution.
\subsection{Environnement matériel :}
Pour la réalisation de ce projet nous avons utilisé un ordinateur portable ayant les caractéristiques suivantes :
\begin{itemize}
    \item Type d’ordinateur : Lenovo Laptop.
    \item Système d’exploitation : CachyOS (Archlinux Based). 
    \item Type de système d’exploitation 64 bits.
    \item  Processeur :  14th Gen Intel(R)Core(TM)i7. 
    \item Mémoire RAM 24 GB et Disque dur 1 TB.
\end{itemize}

\textbf{GITHUB :} GitHub s’impose aujourd’hui comme la plateforme de référence mondiale pour le développement collaboratif. S’appuyant sur la puissance du logiciel de visionnage Git, elle offre aux développeurs un espace sécurisé pour concevoir, héberger et administrer leurs bases de code. Si elle est le pilier incontournable de l’écosystème Open Source, elle accompagne également les entreprises via des dépôts privés hautement protégés.\par
Au-delà du simple stockage, GitHub est un véritable outil de gestion de projet agile. La plateforme intègre des fonctionnalités avancées pour fluidifier le travail d'équipe : un système de suivi des erreurs (bug tracking), la gestion des suggestions d'amélioration, des tableaux de bord pour l'organisation des tâches, ainsi qu'un Wiki dédié pour documenter chaque projet. En devenant le plus grand réservoir de code au monde, GitHub est désormais l'épicentre où convergent l'innovation logicielle et la collaboration technique internationale.\par

\textbf{Swagger :}Est un langage de description d’interface permettant de décrire des API exprimées à l'aide de JSON, Il est utilisé avec toute une série d'outils logiciels open source pour concevoir, créer, documenter et utiliser des Services Web Et qui inclut des outils de documentation automatisée, de génération de code.\par
Swagger s'impose comme une suite de référence de logiciels open source dédiée à l'écosystème du développement web. Plus qu'un simple outil de documentation, il s'inscrit au cœur du cycle de vie des applications en permettant de concevoir, bâtir et consommer des services de manière collaborative. En s'appuyant sur la spécification OpenAPI , Swagger offre une description standardisée et universelle des API REST , garantissant une parfaite interopérabilité entre les machines tout en restant intuitive pour les développeurs. Sa nature open source favorise ainsi une innovation transparente et un enrichissement constant par la communauté, simplifiant l'adoption de normes de qualité industrielle. \par

\textbf{GIT :}Git est un système de contrôle de version distribuée (DVCS) devenu le standard de l'industrie. Il permet un suivi méticuleux de chaque modification du code source grâce à un historique complet et immuable. Véritable pilier de la collaboration, Git facilite le travail simultané de plusieurs développeurs via un système de branches performant, entraînant ainsi les conflits majeurs. En gérant efficacement les différentes versions d'un projet, il garantit l'intégrité des données et offre une flexibilité totale, permettant de naviguer instantanément entre les versions ou de restaurer le projet à un état antérieur en cas d'erreur. \par

\subsection{Gestion de base de données :}
Dans le cycle de développement logiciel, MySQL s'impose comme un véritable « bac à sable » stratégique qui propulse le prototypage rapide et les tests locaux. Sa force réside dans une mise en œuvre quasi instantanée, offrant une expérience de développement sans configuration complexe grâce à des environnements préconfigurés (comme XAMPP ou Docker) qui permettent de lancer une base de données fonctionnelle en quelques secondes. En phase de création, il permet aux développeurs de modéliser et d'itérer sur la structure des données avec une agilité totale, facilitant l'injection de données de test et le débogage en temps réel sans risque pour les systèmes de production. Cette légèreté technique, alliée à une MySQL est un levier d'efficacité indispensable pour passer de l'idée au prototype fonctionnel avec un minimum de friction.\par

\subsection{Interface Login :}
L'interface de connexion constitue la clé de voûte de la sécurité logicielle, orchestrant le processus critique d’authentification pour valider l'identité des usagers avant tout accès. Son rôle principal est de sécuriser le périmètre applicatif tout en assurant une passerelle vers un environnement personnalisé, où chaque utilisateur retrouve ses privilèges spécifiques et ses fonctionnalités dédiées.\par
\begin{itemize}
\item Zones de saisie : identifiant et mot de passe.
\item Bouton de connexion : validation de l'accès.
\item Lien d'aide : récupération du mot de passe oublié.
\item Alertes claires : messages précis en cas d'erreur ou de compte bloqué.
\item Option de visibilité : icône « œil » pour afficher/masquer le texte.
\item Menu Popup Flottante : design ergonomique et réactive.
\end{itemize}

\subsection{Conclusion}
Ce quatrième chapitre concrétise la transition entre la conception et la réalisation de l’application "ERP Rayhan". Nous y détaillons un environnement de développement optimisé, allant du choix stratégique du matériel aux technologies logicielles modernes. Le front-end, conçu avec Flutter Web, assure une expérience moderne via un code unique. À l'instar du back-end, l'application est conteneurisée avec Docker et servie par Nginx. Enfin, l'utilisation de SQL garantit une base de données robuste, flexible et performante.\par
