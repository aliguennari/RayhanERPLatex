\subsection{Environnement matériel :}
Pour la réalisation de ce projet nous avons utilisé un ordinateur portable ayant les caractéristiques suivantes :
\begin{itemize}
    \item Type d’ordinateur : Lenovo Laptop.
    \item Système d’exploitation : CachyOS (Archlinux Based). 
    \item Type de système d’exploitation 64 bits.
    \item  Processeur :  14th Gen Intel(R)Core(TM)i7. 
    \item Mémoire RAM 24 GB et Disque dur 1 TB.
\end{itemize}

L’interface de connexion gère l’authentification et redirige chaque utilisateur vers son environnement selon son rôle.\par
\begin{itemize}
\item Zones de saisie : identifiant et mot de passe.
\item Bouton de connexion : validation de l'accès.
\item Lien d'aide : récupération du mot de passe oublié.
\item Alertes claires : messages précis en cas d'erreur ou de compte bloqué.
\item Option de visibilité : icône « œil » pour afficher/masquer le texte.
\item Menu Popup Flottante : design ergonomique et réactive.
\end{itemize}
